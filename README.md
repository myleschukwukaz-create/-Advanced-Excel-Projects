# Advanced Excel Projects

Five Excel projects showing how I use Microsoft Excel for business analysis, financial modeling, and reporting. Each workbook opens with a **Project Overview** tab and has a **Documentation** tab explaining every sheet.

## Projects

| Project | What I did | Key skills |
|---|---|---|
| **Cairo Consulting: Service Profitability** | Modeled profit across three consulting services and used Solver to find a $1.33M lowest-cost provider mix | Data tables, Solver, Scenario Manager, charts |
| **Expo Events: Trade Show Profit** | Projected profit for three trade shows and found a $47,220 provider plan under a $48K budget cap | Data tables, Solver, scenarios, PivotCharts |
| **Scrub Jay Peripherals: Sales & Profit Projections** | Forecast 2021–2025 sales and gross profit ($515K–$1.41M) across seven growth scenarios | Formulas, absolute/mixed references, VLOOKUP |
| **Content Shop: Contractor & Editing Analysis** | Screened 20 contractors for assignments and analyzed editing project volume | IF/AND/OR, IFERROR, PivotTables, slicers |
| **Valerian State College: Student Activities** | Automated eligibility checks for 30 students and summarized group membership | Structured references, PivotTables, PivotCharts |
